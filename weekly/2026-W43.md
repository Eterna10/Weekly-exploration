## 1. VoiceStudio

- 仓库地址：https://github.com/debpalash/VoiceStudio
- 关键词：语音克隆、TTS、视频配音、本地部署、MCP
- 所属领域：深度学习 / AI
- 本周新增 star：13,581（总计约 82.1k）
- 概述：VoiceStudio 是一个完全本地运行的开源 ElevenLabs 替代品，可以做语音克隆、音色设计、视频配音、听写转录和有声书制作，README 称支持 646 种语言。默认引擎基于 k2-fsa/OmniVoice，也能切换其他引擎，以 Electron 桌面应用、本地 API 和 MCP 服务器三种形式提供。所有流程都在本机硬件上运行，远程服务为可选项。适合重视隐私、想在本地完成语音生成与配音的创作者和开发者。

## 2. xerj

- 仓库地址：https://github.com/xerj-org/xerj
- 关键词：本地搜索引擎、混合检索、RAG、Agent 记忆、Rust
- 所属领域：AI
- 本周新增 star：8,064（总计约 13.2k）
- 概述：xerj 是一个面向 AI Agent 的本地优先搜索引擎兼 MCP 服务器，单个 Rust 二进制就能索引代码、文档、日志、JSONL/CSV 和 PDF。它支持 BM25 全文检索、向量检索和混合检索，用 tree-sitter 解析代码，并提供兼容 Elasticsearch 的 API。项目主打“参考式编码”：Agent 直接查询已建好索引的开源仓库，不再逐个 grep，README 中自家案例称输出 token 降低约 2.7 倍。适合 Claude Code、Cursor 等编码 Agent 用户，以及需要轻量 RAG 或 Elasticsearch 替代方案的开发者。

## 3. ComfyUI

- 仓库地址：https://github.com/Comfy-Org/ComfyUI
- 关键词：扩散模型、节点式工作流、图像生成、本地推理
- 所属领域：深度学习
- 本周新增 star：4,375（总计约 142.1k）
- 概述：ComfyUI 是一个模块化的扩散模型 GUI、API 和后端，用节点图搭建生成流程，Trending 页面描述中自称“世界上最快的本地推理引擎”。用户可以像搭积木一样组合模型加载、采样、后处理等节点，复现和分享复杂工作流。作为生成式 AI 社区的基础设施，它本周仍保持高增速。适合 AIGC 创作者、需要可复现生成流程的研究者和工程师。

## 4. scientific-agent-skills

- 仓库地址：https://github.com/K-Dense-AI/scientific-agent-skills
- 关键词：Agent Skills、AI 科学家、生物信息、化学信息、科研数据库
- 所属领域：AI
- 本周新增 star：3,967（总计约 54.0k）
- 概述：这是一个面向科研场景的 Agent Skills 库，目标是“把任意 AI Agent 变成 AI 科学家”，包含 177 个基于 SKILL.md 的技能，覆盖生物信息、化学信息、临床研究、物理、工程和数据分析等方向。它的思路是用精选的操作指南、校验步骤和科研数据库接入来提高 Agent 处理科学任务的可靠性。项目遵循开放的 Agent Skills 标准，兼容 Claude Code、Cursor、Codex 等工具。适合用 AI Agent 辅助科研的研究人员。

## 5. CLI-Anything

- 仓库地址：https://github.com/HKUDS/CLI-Anything
- 关键词：Agent 原生、CLI 自动生成、工具调用、软件自动化
- 所属领域：AI
- 本周新增 star：3,275（总计约 56.4k）
- 概述：CLI-Anything 由港大 HKUDS 团队开源，目标是让所有软件变成“Agent 原生”，也就是为现有软件自动生成可供 AI Agent 调用的命令行接口，不依赖 GUI 自动化或定制 API。它通过多阶段流水线分析源码，生成带 REPL 和 JSON 输出的 Click CLI，再补上测试和文档，生成的 CLI 直接调用 LibreOffice、Blender 等真实后端。配套的 CLI-Hub 可以用 pip 安装和分发这些 CLI。适合构建 Agent 工具链的开发者。

## 6. Kronos

- 仓库地址：https://github.com/shiyu-coder/Kronos
- 关键词：金融基础模型、K 线、时间序列、Transformer、量化
- 所属领域：深度学习
- 本周新增 star：2,410（总计约 43.3k）
- 概述：Kronos 是面向金融市场“语言”的基础模型，在 45 个以上交易所的 K 线序列上做了预训练。它先用分词器把 OHLCV 数据量化为分层离散 token，再用 decoder-only 自回归 Transformer 进行预训练。开源权重从 Kronos-mini（4.1M）到 Kronos-base（102.3M），Kronos-large 未开源；仓库还提供 KronosPredictor 接口和基于 Qlib 的 A 股微调流程。适合量化研究者和金融时序建模从业者（README 注明回测仅为演示）。

## 7. AirLLM

- 仓库地址：https://github.com/lyogavin/airllm
- 关键词：大模型推理、低显存、逐层加载、端侧部署
- 所属领域：深度学习 / 边缘计算
- 本周新增 star：1,521（总计约 40.4k）
- 概述：AirLLM 是一个 Python 库，通过每次只把一层模型加载到 GPU 的分层推理方式，在小显存设备上运行超大语言模型，基础方案不需要量化。README 称 4GB 显卡可以跑 70B 模型，约 12GB 可以跑 DeepSeek-V3（671B），并支持可选的 4/8 bit 分块压缩来加速。项目还支持 Apple Silicon 上的 macOS，以及冻结权重的 LoRA 训练。适合显存有限、又想在本地或端侧体验和微调大模型的个人开发者（性能数据为 README 自述）。

## 8. xiaozhi-esp32（小智）

- 仓库地址：https://github.com/78/xiaozhi-esp32
- 关键词：ESP32、AI 语音助手、MCP、物联网、离线唤醒
- 所属领域：边缘计算 / AI
- 本周新增 star：588（总计约 31.8k）
- 概述：小智是一套开源的 ESP32 固件，把 Qwen、DeepSeek 等大模型接入低成本硬件，做成 AI 语音聊天机器人。它基于 ESP-SR 实现离线唤醒词，支持 WebSocket 和 MQTT+UDP 传输、Opus 音频流，并通过设备端 MCP 控制扬声器、LED、舵机、GPIO 等外设，通过云端 MCP 扩展智能家居等能力。README 列出 100 多种开发板适配，当前需要 ESP-IDF v6.0.1 及以上版本。适合 AI 硬件爱好者、创客和嵌入式开发者。

## 9. uzu

- 仓库地址：https://github.com/trymirai/uzu
- 关键词：端侧推理引擎、Rust、Apple Silicon、Metal、隐私
- 所属领域：边缘计算
- 本周新增 star：198（总计约 2.5k）
- 概述：uzu 是一个高性能 AI 模型推理引擎，主打把模型直接部署在应用内，实现低延迟、数据不出设备、无推理费用。核心是 Rust crate，提供 Python、Swift、TypeScript 绑定，利用 Apple 设备的统一内存，并支持 Metal 和 CPU 后端。项目还提供交互式 CLI 和兼容 OpenAI 的 HTTP 服务。适合想在 macOS/iOS 等终端设备上集成本地大模型的应用开发者。

## 10. FinRL（持续活跃的经典项目）

- 仓库地址：https://github.com/AI4Finance-Foundation/FinRL
- 关键词：深度强化学习、量化交易、Stable Baselines3、金融环境
- 所属领域：强化学习
- 本周新增 star：128（总计约 16.8k）
- 概述：FinRL 是最早的开源金融强化学习框架之一，按“市场环境 – DRL 智能体 – 金融应用”三层组织，提供训练、测试、交易一体的流水线。它集成了 Stable Baselines3 的 A2C、DDPG、PPO、TD3、SAC 等算法，并附有道琼斯 30 成分股交易教程，与均值方差优化和 DJIA 基准做对比。官方把它定位为教学、基准测试和研究原型用的经典端到端框架，生产场景推荐 FinRL-X / FinRL-Trading。适合学习强化学习落地应用的学生和量化研究者。本周它出现在 Jupyter Notebook 分榜上，是榜单中少见的强化学习项目。

## 本周趋势小结

本周热度依然集中在 AI Agent 生态：本地检索与记忆（xerj）、科研技能库（scientific-agent-skills）、软件 Agent 化（CLI-Anything）这类“给 Agent 配工具”的项目增长最快。本地化和端侧化是第二条主线，从完全本地的语音生成（VoiceStudio）、低显存大模型推理（AirLLM），到 ESP32 语音终端（小智）和 Apple 设备推理引擎（uzu），都在把模型推向用户自己的设备。垂直领域基础模型（Kronos）也持续受到关注。强化学习只有经典框架 FinRL 少量上榜，联邦学习方向本周没有检索到进入 Trending 或明显增长的项目。
