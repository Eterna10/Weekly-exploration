## 1. VoiceStudio（持续上榜）

- 仓库地址：https://github.com/debpalash/VoiceStudio
- 关键词：语音克隆、TTS、视频配音、本地部署、MCP
- 所属领域：深度学习 / AI
- 本周新增 star：12,825（总计约 95.7k）
- 概述：VoiceStudio 在上周（W43）已收录，本周仍以 1.28 万新增 star 位居 Python 分榜第一，因此标注「持续上榜」。它是一个完全本地运行的开源 ElevenLabs 替代品，支持语音克隆、视频配音、听写转录和有声书制作，所有流程都在用户自己的硬件上完成。两周内总 star 从约 8.2 万涨到约 9.6 万，说明“本地化语音生成”需求依然旺盛。适合重视隐私、想在本地完成语音生成与配音的创作者和开发者。

## 2. DeepTutor

- 仓库地址：https://github.com/HKUDS/DeepTutor
- 关键词：AI 辅导、个性化学习、RAG、分层记忆、Agent
- 所属领域：AI
- 本周新增 star：7,509（总计约 51.7k）
- 概述：DeepTutor 是港大 HKUDS 团队开源的 Agent 原生学习工作台，定位为“终身个性化辅导”，把答疑、解题、出题、研究、可视化和练习放进同一个运行时和会话上下文中。知识库层可以按库选择 LlamaIndex、PageIndex、GraphRAG、LightRAG 等多种检索引擎；记忆采用 L1 轨迹、L2 事实、L3 跨场景归纳的分层文件存储，可直接查看，不是黑盒向量库。它还支持 MCP、CLI 应用和社区技能扩展，并能在对话中调用 Claude Code、Codex 等 Agent，10 月 28 日刚发布 v1.7.0。适合自学者、教师和想自建 AI 教学平台的开发者。

## 3. TradingAgents

- 仓库地址：https://github.com/TauricResearch/TradingAgents
- 关键词：多智能体、LLM、量化交易、LangGraph、回测
- 所属领域：AI
- 本周新增 star：5,557（总计约 118.7k）
- 概述：TradingAgents 是一个基于 LangGraph 的多智能体 LLM 金融交易框架，模拟一家交易公司的分工：基本面、情绪、新闻和技术分析师并行出报告，多空研究员辩论，交易员给出仓位建议，再由风控和投资组合经理审批。它支持 OpenAI、Claude、Gemini、DeepSeek、Qwen、Ollama 本地模型等十多种模型来源，并提供按申报时点取数、避免未来函数的回测，以及会总结过往决策得失的持久记忆。10 月发布的 v0.7.1 修复了组合、价格和 SEC 报表等多处问题。README 明确说明它只是研究脚手架，不构成投资建议，适合研究多智能体系统和金融 AI 的研究者与开发者。

## 4. OpenShell

- 仓库地址：https://github.com/NVIDIA/OpenShell
- 关键词：Agent 沙箱、安全运行时、网络策略、凭据隔离、形式化验证
- 所属领域：AI
- 本周新增 star：3,563（总计约 20.8k）
- 概述：OpenShell 是 NVIDIA 开源的自主 AI Agent 安全运行时：用户用策略声明每个 Agent 能访问哪些文件、网络和凭据，OpenShell 负责强制执行。每个 Agent 跑在独立沙箱中，内核层限制文件读取和系统调用，每个出站连接都先过策略检查；Agent 拿不到真实凭据，凭据只在请求发往获批端点时才由系统注入。策略变更前会用证明器检查是否引入了高风险访问（例如新主机获得凭据），这类变更需要人工审核。项目提供 Python、TypeScript、Go、Rust SDK 和 Helm 部署方式，适合需要让 Agent 安全接触真实环境的团队。

## 5. microduck

- 仓库地址：https://github.com/pollen-robotics/microduck
- 关键词：双足机器人、强化学习、PPO、sim2real、Rust
- 所属领域：强化学习 / 边缘计算
- 本周新增 star：3,106（总计约 13.2k）
- 概述：microduck 是 Pollen Robotics 的小型双足“鸭子”机器人（约 25 cm、800 g）的机载软件，README 称之为“鸭子的大脑”。行走等动作策略在配套仓库 microduck_rl 中用 MuJoCo + PPO 训练，经过域随机化做 sim2real 迁移，再导出为 ONNX，由本仓库在 RK3566 上以 50 Hz 控制回路驱动 15 个舵机。软件用 Rust 写成，拆分为控制、更新、配置、手柄等多个守护进程，支持行走、轮式滑行、捡东西、摔倒后站起和踢球。社区已出现中文复刻项目（如 kissqy/Microduck-kissqy），适合想动手实践强化学习落地和端侧机器人控制的爱好者与研究者。

## 6. RuView

- 仓库地址：https://github.com/ruvnet/RuView
- 关键词：WiFi 感知、CSI、ESP32、生命体征监测、隐私
- 所属领域：边缘计算 / 深度学习
- 本周新增 star：2,479（总计约 101.8k）
- 概述：RuView 用普通 WiFi 信号做空间感知，靠约 9 美元一块的 ESP32-S3 采集信道状态信息（CSI），无需摄像头就能检测人员存在、呼吸和心率。信号经带通滤波提取生命体征，存在检测使用发布在 Hugging Face 上的预训练模型，全部处理在边缘设备本地完成，不依赖云端。它可接入 Home Assistant、Matter 生态，并提供给 AI Agent 用的 MCP 服务器。README 自己标注为 beta：端侧姿态模型仍处于早期，生命体征输出未经验证，也不是医疗设备。适合智能家居玩家、养老与睡眠监测研究者和嵌入式开发者。

- 所属领域：深度学习

## 9. AutoTavern（TavernGym / TavernBench）

- 仓库地址：https://github.com/MCG-NJU/AutoTavern
- 关键词：强化学习环境、游戏 AI、基准测试、Rust 模拟器、LLM Agent
- 所属领域：强化学习 / AI
- 本周新增 star：未获取（仓库于 2026-10-24 创建，检索时总计约 178）
- 概述：AutoTavern 是南京大学 MCG 团队论文《Build, Don't Play》的代码与数据，包括 TavernGym 和 TavernBench 两部分。TavernGym 是用 Rust 编写、带 Python 绑定的《炉石传说》酒馆战棋单人模式模拟器，结果确定、可存档回滚，提供合法动作掩码，以及单席位对脚本 bot、批量并行和自博弈等接口（245 个离散动作、3227 维数值特征）。TavernBench 包含 960 道覆盖战斗、站位、经济等 8 类的决策题，已公开 368 题评测集，评分不需要模型 API。训练好的 TavernAgent 权重和训练代码未开源，适合做游戏强化学习和 LLM 决策评测的研究者。

## 本周趋势小结

本周 Trending 总榜几乎被编码 Agent 的 Skill 和插件刷屏，周报关注领域内增长最快的仍是“Agent + 垂直场景”应用，例如学习辅导（DeepTutor）和金融多智能体（TradingAgents），Agent 安全运行时（OpenShell）也开始受到关注。强化学习本周有亮点：microduck 让 PPO + sim2real 训练出的策略跑在低成本双足机器人上，AutoTavern 则开放了一套高质量的游戏 RL 环境和基准。边缘侧方向，WiFi 感知（RuView）和本地语音生成（VoiceStudio）热度不减。联邦学习依旧没有项目进入 Trending，Flower 等老牌框架靠持续发版维持活跃，并开始向 Agent 场景延伸。
