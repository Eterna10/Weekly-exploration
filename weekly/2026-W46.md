## 1. Auto Ontology（持续上榜）

- 仓库地址：https://github.com/NVIDIA/auto-ontology
- 关键词：本体构建、语义层、Text-to-SQL、知识图谱、MCP
- 所属领域：AI
- 本周新增 star：5,802（总计约 12.5k）
- 概述：Auto Ontology 是 NVIDIA 开源的 Python 框架，在企业数据之上自动构建基于图的语义推理层，让 AI Agent 能用可解释、确定性的方式把业务问题转换成 SQL 查询。它从元数据生成本体、对齐不同系统中的指标定义，并通过 MCP、CLI 和 API 对外提供，生成的查询会对照已认证定义和数据血缘做校验。上周首次收录时新增 7,648 star，本周又新增 5,802，总数增长到约 1.25 万，热度没有明显回落。适合做数据分析 Agent、企业知识问答的团队。

## 2. daily_stock_analysis

- 仓库地址：https://github.com/ZhuLinsen/daily_stock_analysis
- 关键词：LLM 应用、股票分析、多市场行情、GitHub Actions、决策看板
- 所属领域：AI
- 本周新增 star：3,569（总计约 71.6k）
- 概述：这是一个用大模型做每日自选股分析的系统，覆盖 A 股、港股、美股、日韩及台股和 ETF，自动生成带评分、趋势、买卖点位、风险提示和操作清单的“决策看板”报告，并推送到企业微信、飞书、Telegram、邮件等渠道。它汇总行情、K 线、技术指标、新闻公告和基本面数据，模型可选 Gemini、Claude、OpenAI 兼容接口（如 DeepSeek、Qwen）或本地 Ollama，还带有 Web 工作台、回测、持仓跟踪和内置 15 种策略的 Agent 问答。推荐部署方式是 Fork 后用 GitHub Actions 定时运行，默认在北京时间工作日 18:00 执行。README 明确说明仅供学习研究、不构成投资建议，适合想学习“LLM + 数据源 + 定时任务”完整落地方式的开发者和个人投资者。

## 3. MuJoCo

- 仓库地址：https://github.com/google-deepmind/mujoco
- 关键词：物理仿真、机器人、强化学习环境、MJX、接触动力学
- 所属领域：强化学习 / 深度学习
- 本周新增 star：1,671（总计约 17.9k）
- 概述：MuJoCo（Multi-Joint dynamics with Contact）是 Google DeepMind 维护的通用物理引擎，是机器人学和强化学习研究中最常用的仿真器之一。它提供面向性能的 C API、把 XML 模型预编译成运行时数据结构的编译器，以及桌面和浏览器中的交互式可视化；Python 绑定可直接从 PyPI 安装，另有基于 JAX 的 MJX 分支，用于在加速器上做大规模并行仿真。生态方面有 dm_control、Unity 插件以及 OpenSim、SDFormat、Onshape 等格式转换工具。本周以 1,671 新增 star 位列 C++ 分榜第一，也进入了总榜，适合做机器人控制、具身智能和强化学习的研究者与工程师。

## 4. Edge0

- 仓库地址：https://github.com/Edge0-AI/Edge0
- 关键词：端侧大模型、Latent MoE、SSD 流式加载、路由预测、本地推理
- 所属领域：边缘计算 / 深度学习
- 本周新增 star：未获取（2026-09-08 创建，检索时总计约 10.9k，11 月 13 日发布新版本）
- 概述：Edge0 是一个流式 MoE 推理框架，目标是在消费级硬件上运行大型稀疏模型，口号是“笔记本跑 145B，手机跑 35B”。它在 11 月 13 日发布了基于 Qwen3.8-Flash-Next 改造的 edge0-145b/120b 模型：采用 Latent MoE 结构压缩专家输入、保持注意力全宽，每个 token 从 512 个专家中路由 10 个，并以原生 4 bit 训练。推理时未缓存的专家可通过 `--mmap-experts` 从 SSD 按需读取，配合可训练的路由预测提前加载；作者自测 145B Q3_K 在 24 GB 的 RTX 5090 D 上 Agent 场景解码约 121 tok/s，在 M2 Ultra 上约 57 tok/s。35B 版本支持 Linux、Windows、Android 的 CPU 推理以及 macOS/iOS 的 Metal。框架代码为 Apache-2.0，模型权重另有社区许可，商用服务有限制，适合想在本机或手机上跑大模型的开发者和研究 MoE 卸载的研究者。

## 5. Mika

- 仓库地址：https://github.com/wangzan101/Mika
- 关键词：手机 Agent、GUI 自动化、Android、视觉操作、隐私
- 所属领域：AI / 边缘计算
- 本周新增 star：未获取（2026-10-29 创建，检索时总计约 8.5k）
- 概述：Mika 是一个开源（Apache-2.0）的 Android 端 AI Agent：用自然语言下达任务后，它在后台隐藏屏幕上像人一样“看屏幕、找按钮”，通过点击、输入和滑动操作 App 与网页，不依赖任何 App 的 API 或逐个适配。它没有自有服务器，模型由用户配置，可接 DeepSeek、Claude、OpenAI、Gemini 等云服务，也可通过 Ollama、LM Studio 或局域网自定义端点使用自部署模型；密钥、记忆和对话记录加密保存在手机本地。功能上包括“询问 / 自主”两种模式（花钱前先确认）、定时与条件任务、每个会话独立的 Linux 沙箱、把完成的任务沉淀为可复用技能，并内置大量国内 App 的使用知识。创建两周即获约 8.5k star，适合研究移动端 GUI Agent 的开发者和想让手机自动完成日常操作的用户；README 也提醒自动化操作第三方 App 可能违反其服务条款。

## 6. EAGLE-4

- 仓库地址：https://github.com/eagle-hq/EAGLE-4
- 关键词：投机解码、推理加速、草稿模型、SGLang、vLLM
- 所属领域：深度学习
- 本周新增 star：未获取（2026-10-20 创建，检索时总计约 1.3k）
- 概述：EAGLE-4 是知名投机解码系列 EAGLE / EAGLE-2 / EAGLE-3 的最新版本官方推理代码，用小型草稿模型预测多个 token、再由目标模型并行验证，保证输出与目标模型单独生成完全一致。配套的 `eagle-harness` 会根据实测开销自动决定每步推测多远，可接入 SGLang、vLLM 和 TokenSpeed 等推理引擎，也支持 AMD MI355X（ROCm）。README 给出的数据中，以 Qwen3.8-27B 为目标模型，在 4×B300 上单请求吞吐提升可达 3.42×（SGLang），64 并发时仍有约 1.4× 的提升；论文以 PDF 形式放在仓库中，草稿模型已发布在 Hugging Face。适合负责大模型线上推理部署、关注延迟和吞吐优化的工程师。

## 7. Voicebox

- 仓库地址：https://github.com/jamiepine/voicebox
- 关键词：语音克隆、TTS、语音听写、本地优先、MCP
- 所属领域：深度学习 / 边缘计算
- 本周新增 star：1,093（总计约 60.6k）
- 概述：Voicebox 是一款免费开源、本地优先的 AI 语音工作室，把语音合成/克隆和语音听写合并在一个桌面应用里，README 称模型、声音数据和录音都不会离开用户的机器。它集成了 8 种 TTS 引擎（Qwen3-TTS、Chatterbox、HumeAI TADA、Kokoro 等），支持 23 种语言和最长 5 万字符的长文本合成；听写部分使用 Whisper（MLX 或 PyTorch），还可用本地 Qwen3 小模型润色文本或赋予“人设”。它通过 MCP 工具和 REST 接口让 AI Agent 用指定声音“说话”，技术栈为 Tauri + React + FastAPI，支持 Apple Silicon、Windows CUDA/DirectML、Linux ROCm 等。适合做播客、有声书、游戏配音的创作者，以及需要语音输入输出能力的 Agent 开发者。

## 8. llama.cpp

- 仓库地址：https://github.com/ggml-org/llama.cpp
- 关键词：LLM 推理、量化、GGUF、端侧部署、C/C++
- 所属领域：边缘计算 / 深度学习
- 本周新增 star：1,086（总计约 134.9k）
- 概述：llama.cpp 是基于 ggml 的纯 C/C++ 大模型与多模态模型推理项目，无外部依赖，目标是以最少配置在各种硬件上获得最佳性能。它支持 1.5 到 8 bit 整数量化，覆盖 Apple Silicon（Metal）、x86 AVX/AMX、RISC-V 向量扩展，以及 CUDA、HIP、MUSA、Vulkan、SYCL、WebGPU、CANN、Hexagon 等十余种后端，并可把超出显存的模型拆分到 CPU+GPU 混合运行。工具链包括命令行、OpenAI 兼容的 llama-server 和 GBNF 语法约束输出，事实上已成为本地/端侧推理生态的底座（本期收录的 PrivateLM 就基于它）。本周位列 C++ 分榜第二，适合所有需要在本地、边缘设备上部署开源模型的开发者。

## 9. PrivateLM（cross-platform-llm-client）

- 仓库地址：https://github.com/orailnoor/cross-platform-llm-client
- 关键词：端侧推理、Flutter、llama.cpp、离线聊天、Vulkan
- 所属领域：边缘计算 / AI
- 本周新增 star：782（总计约 2.3k）
- 概述：PrivateLM 是一个用 Flutter 编写的跨平台 AI 聊天客户端，可以在手机上离线运行 GGUF 模型，也可以切换到 OpenAI、Anthropic、Gemini、Kimi 等云端 API。端侧推理通过作者自研的 Flutter 插件封装 llama.cpp，Android 上支持 Vulkan GPU 加速，iOS 走 Metal，并支持 Qwen2-VL 本地图像理解。它首次启动时会检测设备内存并推荐上下文和生成长度，内置 ChatML、Llama-3、Gemma、Phi 等对话模板，聊天记录用 Hive 存在本地，只有云端模式才会把数据发出设备。本周位列 C++ 分榜第三，适合想在手机上体验离线大模型、或参考 Flutter + llama.cpp 集成方案的移动开发者。

## 10. AgentEnv Framework

- 仓库地址：https://github.com/scaleapi/agentenv-framework
- 关键词：强化学习环境、Agent 评测、容器化、OpenEnv、奖励验证
- 所属领域：强化学习 / AI
- 本周新增 star：未获取（2026-09-24 创建，检索时总计约 435，近一周有推送）
- 概述：AgentEnv Framework 是 Scale AI 开源的 Python SDK 和 CLI，用于构建、部署和运行面向 Agent 的强化学习环境以及给 Agent 打分的任务。环境是遵循开放协议 `agentenv-framework-protocol` 的容器化服务，框架负责把它们构建成带版本的镜像、部署在网关之后、让 Agent 接入执行，再由任务中定义的验证器给出分数，可直接作为强化学习的奖励。每个任务都可以作为 OpenEnv 环境被任意 OpenEnv 客户端调用，环境、任务和 Agent 可打包成 Bundle 发布到 Hugging Face Hub 并按提交版本复现。它是本周检索到的 Agentic RL 基础设施方向较活跃的新项目，未进入 Trending，适合需要搭建可复现 RL 训练/评测环境的研究者和工程团队。

## 本周趋势小结

本周最突出的方向仍是“把大模型搬到本地和端侧”：Edge0 用 Latent MoE 加 SSD 流式加载让 145B 模型在单张消费级显卡上跑出百 tok/s 量级，llama.cpp 和基于它的 PrivateLM 继续推动手机离线推理，Voicebox 则把语音合成与听写都做成了本地应用。推理加速方面，EAGLE-4 把投机解码推进到新一代，并直接对接 SGLang、vLLM 等主流引擎。AI 应用侧，Mika 代表的手机 GUI Agent 两周内获得约 8.5k star，股票分析等垂直 LLM 应用也保持高热度。强化学习方面，MuJoCo 登上 C++ 分榜第一，Agent 强化学习环境基础设施（AgentEnv Framework）开始出现；联邦学习本周没有检索到表现突出的新项目。
