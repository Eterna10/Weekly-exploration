## 1. Auto Ontology

- 仓库地址：https://github.com/NVIDIA/auto-ontology
- 关键词：本体构建、语义层、Text-to-SQL、知识图谱、MCP
- 所属领域：AI
- 本周新增 star：7,648（总计约 8.9k）
- 概述：Auto Ontology 是 NVIDIA 开源的 Python 框架，用于在企业数据之上构建基于图的语义推理层，让 AI Agent 能可靠地回答业务问题。它从元数据自动生成本体，对齐不同系统中的指标定义，再通过 MCP、CLI 和 API 对外提供，并把自然语言问题转换成 SQL 在已连接的数据库上执行。流程分为发现、落地、校验、暴露、学习五个阶段，生成的查询会对照已认证的定义和数据血缘做校验，答案附带出处。它支持 PostgreSQL、Snowflake、Databricks 等十种 SQL 引擎，模型默认走 NVIDIA NIM，也可换成自托管或兼容 OpenAI 的端点。本周 Python 分榜增速第一，适合做数据分析 Agent 和企业知识问答的团队。

## 2. Graphify

- 仓库地址：https://github.com/Graphify-Labs/graphify
- 关键词：代码知识图谱、tree-sitter、编码助手、图检索、Leiden 聚类
- 所属领域：AI
- 本周新增 star：4,577（总计约 143.5k）
- 概述：Graphify 把代码库连同文档、SQL schema、配置文件和 PDF 一起转换成可查询的知识图谱，以 `/graphify` 技能的形式接入 Claude Code、Cursor、Codex、Gemini CLI 等编码助手。代码部分用 tree-sitter 在本地解析 AST，不消耗 LLM 调用；文档、图片等非代码内容才走模型做语义抽取。每条边都标注为“源码中明确存在”或“工具推断”，检索靠图遍历而不是向量库，并用 Leiden 社区发现做模块聚类。适合需要让编码助手理解大型代码库、或希望团队共享项目上下文的开发者。

## 3. Hex

- 仓库地址：https://github.com/anomalyco/hex
- 关键词：语音听写、本地推理、隐私、跨平台、Rust
- 所属领域：边缘计算 / AI
- 本周新增 star：4,306（总计约 5.5k）
- 概述：Hex 是一款本地语音听写工具：按住快捷键说话，松开后在本机完成转写，并把文字粘贴到当前应用。首次运行会下载语音模型，此后 README 称“没有任何数据离开你的机器”。它支持 Apple Silicon 的 macOS、Windows x64/ARM64 和 Linux x86_64/ARM64，提供 Homebrew、AUR、Nix、deb/rpm 等多种安装方式。README 没有写明具体用的是哪个语音模型；项目不接受 PR，只通过 issue 收集反馈。本周以 4,306 新增 star 位列 Rust 分榜增速前三，适合重视隐私、希望在端侧完成语音输入的用户。

## 4. colibri

- 仓库地址：https://github.com/JustVugg/colibri
- 关键词：MoE 推理、专家卸载、NVMe 流式加载、C 语言、本地部署
- 所属领域：深度学习 / 边缘计算
- 本周新增 star：3,214（总计约 48.5k）
- 概述：colibri 是用 C 编写的大型 MoE 模型推理引擎，核心思路是三级存储：最常用的专家放在 GPU（CUDA 或 Vulkan），次常用的放在内存，冷门专家按需从 NVMe 流式读取，稠密部分常驻内存。专家放置根据用户自己的实际路由统计学习，并配合逐层 LRU 缓存、路由预读和多 SSD 镜像；README 强调放置策略只影响速度，不改变路由结果和权重精度。它支持 GLM、Kimi K3、DeepSeek V4 Flash、Qwen 等十余个模型家族，可导入 GGUF，并提供兼容 OpenAI/Anthropic 的本地 API。作者给出的数据中，Qwen3.6-35B-A3B 在集成显卡 Radeon 780M 上解码约 9.9 tok/s。适合想在自有硬件上跑超大开源模型的个人和研究专家调度的研究者。

## 6. Handy

- 仓库地址：https://github.com/cjpais/Handy
- 关键词：离线语音识别、Whisper、Parakeet、VAD、桌面应用
- 所属领域：边缘计算 / 深度学习
- 本周新增 star：2,608（总计约 37.8k）
- 概述：Handy 是一款免费、开源、完全离线的跨平台语音转文字桌面应用，按快捷键说话后文字直接出现在任意输入框中。整个流程在本地完成：先用 Silero VAD 过滤静音，再由用户选择的模型转写，可选 Whisper（Small/Medium/Turbo/Large，有 GPU 时自动加速）或针对 CPU 优化、能自动识别语言的 Parakeet V3。它支持 Windows、macOS 和 Linux，定位是开放、可扩展的无障碍工具。与 Hex 同属本周热门的“端侧语音输入”方向，适合需要隐私友好听写工具的用户，以及想研究端侧 ASR 落地的开发者。

## 7. kimi-k3-in-c

- 仓库地址：https://github.com/FareedKhan-dev/kimi-k3-in-c
- 关键词：CPU 推理、C99、MoE、MXFP4 量化、权重流式加载
- 所属领域：深度学习 / 边缘计算
- 本周新增 star：1,490（总计约 11.0k）
- 概述：这个项目用可移植的 C99 实现了 2.78 万亿参数 Kimi K3 的推理，不依赖 BLAS、框架或 GPU，整个引擎约 176 KB。磁盘上的 checkpoint 约 1.56 TB，稠密主干按内存预算部分常驻、其余流式读取，1.45 TB 的路由专家从不常驻内存，而是直接从磁盘读取后计算，再配合专家 LRU 缓存；作者实测峰值内存仅 8.24 GB。README 给出的速度是 8 GB 内存的普通笔记本每个 token 约 26.5 秒、128 GB 以上工作站约 5.6 秒，并强调不同机器输出逐字节一致。它更像一个讲清楚“如何把超大模型塞进小机器”的系统工程样例，README 本身就是一篇长篇技术说明，适合研究 LLM 推理底层和内存优化的系统程序员。

- 所属领域：深度学习

- 概述：Diy-LLM 是 Datawhale 社区基于 Stanford CS336《从零构建语言模型》改编的中文课程，不是逐字翻译，而是按“构建 LLM 的工程流程”重新编排，目前有 16 章正文和 6 个配套作业。内容从 BPE 分词器、RoPE/RMSNorm/SwiGLU 架构、MoE、GPU 与 Triton 编程、FlashAttention-2、分布式训练、Scaling Laws，一直讲到推理优化、SFT/DPO、GRPO/RLVR 和多模态。作业提供可运行实现，还补充了 Qwen、DeepSeek 等国产模型案例、C-EVAL 评测，以及 CPU/Mac MPS 调试建议。适合已有 PyTorch 基础、想系统掌握大模型训练全链路的中文学习者。

## 9. FPO（Flow Policy Optimization）

- 仓库地址：https://github.com/tuotuoLyu/FPO
- 关键词：强化学习微调、VLA、流匹配策略、PPO、机器人操作
- 所属领域：强化学习 / 深度学习
- 本周新增 star：未获取（仓库于 2026-10-29 创建，检索时总计约 130）
- 概述：FPO 是中科院自动化所团队 ICRA 2026 论文《Reinforcement Fine-Tuning of Flow-Matching Policies for Vision-Language-Action Models》的官方代码，用 PPO 式裁剪更新对流匹配 VLA 策略 π0 做在线强化学习微调。由于流匹配模型的似然难以计算，FPO 改用每个样本的条件流匹配（CFM）损失变化来构造重要性比率，无需求解 ODE 似然或雅可比迹；优势函数由 Q 集成取保守最小值并结合 GAE 估计。论文报告在 LIBERO 四个任务集上平均成功率达到 87.2%，高于 π0-FAST 的 85.5%，ALOHA 双臂任务也有实验。代码把论文中的每个消融设置都做成了开关，适合研究 VLA 后训练和具身强化学习的研究者。

## 10. Fractal（FractalWorkspace）

- 仓库地址：https://github.com/Fractal-Compute-Orchestrations/FractalWorkspace
- 关键词：联邦学习、端侧训练、FedAvg、Android、分布式算力
- 所属领域：联邦学习 / 边缘计算
- 本周新增 star：未获取（总计约 9.2k，近一周有推送）
- 概述：Fractal 是一个分布式算力编排与边缘智能框架，目标是在保护用户隐私和设备健康的前提下，把分散在手机上的消费级算力用于大模型的联邦训练。系统分两部分：Python 编写的中心控制面 FractalCore，负责多租户隔离、数据分片分配、模型计算图切分与 INT4 量化、FedAvg 权重聚合和算力预算控制；Kotlin 编写的 Android 端 FractalAndroid，负责在端侧做训练和内存映射推理，并在设备过热或电量不足时自动暂停任务。它是本周检索到的联邦学习方向中活跃度较高的新项目（2026 年 5 月创建），但没有进入 Trending，适合研究跨设备联邦学习和移动端训练调度的开发者。

## 本周趋势小结

本周最明显的趋势是“在小机器上跑大模型”：colibri 和 kimi-k3-in-c 都通过把 MoE 专家放在 GPU、内存、NVMe 多级存储中按需读取，让万亿参数级模型在消费级硬件上也能运行。端侧语音输入同样升温，Hex 和 Handy 两款完全本地运行的听写工具同时进入 Rust 分榜前列。AI 应用方向，NVIDIA Auto Ontology 和 Graphify 都在为 Agent 提供结构化的语义层或知识图谱，说明“给 Agent 提供可信上下文”正成为新热点。强化学习和联邦学习本周仍没有项目进入 Trending，亮点主要来自论文代码（FPO 的 VLA 强化学习微调）和面向手机算力的联邦训练框架（Fractal）。
